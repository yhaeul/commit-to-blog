# implement-next

`docs/checklist.md`에서 다음 미완료 커밋을 찾아 구현하고, 완료 후 `/commit-msg`로 커밋 메시지를 작성한다.
**한 번 호출에 커밋 하나만** 담당한다. 다음 커밋은 사용자가 커밋을 완료한 뒤 다시 `/implement-next`를 호출한다.

## 실행 순서

1. `docs/checklist.md`를 읽어 **다음 구현 대상 커밋**을 찾는다.
   - 세부 항목(`  - [ ]`)이 하나라도 남아있는 최상위 항목 중 가장 앞선 것을 선택한다.
   - 세부 항목이 없는 최상위 항목(계획이 안 된 것)은 건너뛴다 — 먼저 `/plan-next`를 실행하도록 안내한다.
   - 모든 항목이 완료되어 있으면 "모든 항목이 완료되었습니다." 라고 안내하고 종료한다.

2. 찾은 커밋의 세부 항목을 사용자에게 보여주고 구현을 시작한다.
   ```
   ## 🔨 구현 시작: 커밋 #N — <제목>
   - [ ] 항목 1
   - [ ] 항목 2
   ...
   ```

3. 세부 항목을 **순서대로** 구현한다.
   - 관련 문서(`docs/architecture.md` 등)를 참고해 설계에 맞게 구현한다.
   - 각 항목 구현 완료 시 `docs/checklist.md`에서 해당 `  - [ ]`를 `  - [x]`로 체크한다.

4. 모든 세부 항목 구현 후 `npm run build`를 실행한다.
   - 빌드 실패 시: 오류를 수정하고 재확인한다. 수정이 완료되면 계속 진행한다.
   - 빌드 성공 시: 최상위 항목도 `- [ ]` → `- [x]`로 체크한다.

5. 빌드 성공 후 다음 안내를 표시하고 종료한다.
   ```
   구현 완료. /commit-msg 로 커밋 메시지를 작성한 뒤, 커밋 후 /implement-next 를 다시 실행하면 다음 커밋을 진행합니다.
   ```

## 주의사항

- 한 번 호출에 커밋 하나만 구현한다. 사용자가 커밋을 완료하기 전에 다음 커밋을 시작하지 않는다.
- 설계(`docs/architecture.md`)와 다른 방향으로 구현하지 않는다. 설계 변경이 필요하면 구현 전에 사용자에게 알린다.
- 빌드 실패는 커밋 전에 반드시 해결한다.
